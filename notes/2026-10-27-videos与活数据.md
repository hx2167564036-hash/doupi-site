# 2026-10-27 /videos 重做 + 首页接活数据

主题 `theme-doupi` 上线后第二轮改动。目标是两件事：把 `/videos` 从「灰底占位卡」改成真正的视频页，把首页里写死的数字换成从站点真实数据算出来的。

## 一、首页数字现在是真的

以前首页的 492 / 476 / 3,046 / 72 是构建时写死的常量，发一篇新记录就要改一遍模板。现在改成运行时算：

- `theme-doupi/assets/js/live.js`（新增，所有页面都加载）
  - 拉公开内容 API：`GET /apis/api.content.halo.run/v1alpha1/posts?page=N&size=100`，**page 从 1 开始**（`page=0` 和 `page=1` 是同一页，这是踩到的第一个坑）。
  - 分页取全量（502 篇 = 6 页），按 `metadata.name` 去重。
  - 日期从 slug / 标题里的 `YYYY-MM-DD` 取；Day 号用 `day[-_ ]?(\d{1,4})`；有 Day 号但没日期的，用同号帖反查日期（那 10 篇雅思/复习资料没有日期，直接不计入天数）。
  - 算出 `posts / days / span / blank / first / last`，再读 `/themes/theme-doupi/assets/data/stats.json` 补 `images / pdfs`。
  - 结果写 `sessionStorage['doupi-live-v1']`，TTL 30 分钟；页面上的 `[data-live]`、`[data-live-count]`、`#words` 由它填。
- `assets/js/home.js` 新增 `window.doupiApplyNumbers()` 与 `window.doupiSetStatement()`：固定滚动区的大数字、逐字点亮的声明段（要重新切 span）都跟着变。
- `probe/build_stats.py`（新增）：SSH 上去数附件目录里的图片与体积，写 `assets/data/stats.json`（`images:3046, attachmentsBytes:5873244713, pdfs:492`）。

实测：**492 篇 / 476 天有字 / 72 天留白 / 3,046 张图**，声明段自动变成「写到 2026 年 10 月 8 日的第 492 篇……72 天没写」。

留了个旧数字给你参考：之前写的 3,169 张是 fast-note-sync 的 temp 目录文件数（那批其实是重复暂存），不是站点图片数；现在按 `attachments/upload` 实数。

## 三、这轮踩的五个坑

1. **API 分页是 1 起始的**：先按 0 起始写，第一页重复、末页拿不到，统计成 500 篇 / 490 天 —— 比真实少 2 篇。改成 `page=1..ceil(total/100)` 后才是 502 / 492。
2. **`serve_assets.py` 只传白名单后缀**（css/js/webp/woff2/svg/png），`.json` 被跳过 → `stats.json` 404，图片数一直不更新。已把 `.json` 加进口令。
3. **`var(--pad)` 在 base.css 里没定义**：`/videos` 的 `.vwrap` 用了它，桌面靠 `max-width` 居中看不出来，手机端贴边（390 宽时标题顶到 x=0）。在 `:root` 补 `--pad:clamp(20px,4.6vw,68px)`。
4. **`.vids-more` 是 `.fade` 元素**，滚动揭示没触发时永远 opacity:0（整行「进视频页看全部 3 个作品」看不见）。给 `.vids-more.fade` 单独设为常驻可见。
5. **封面标题重复**：首页三张卡的封面上有标题、下方 caption 又有标题。去掉封面那层，只留 caption。

## 五、还需要你人工确认的一件事

无头浏览器里点开视频卡后，B 站 iframe **已注入、尺寸正确**（343×193），但播放器画面是黑的 —— 这是 headless 环境的限制（B 站播放器要 cookie / 用户手势）。**请你在普通浏览器里打开 https://doupi123.top/videos，点一下第一张卡的封面**，确认能出画面。如果也是黑的，说明 B 站把播放器限制在了它的白名单 referer 上，那我们就退一步：封面点击直接新开 B 站页面。

## 六、改这些文件后怎么发布

```powershell
$env:PYTHONPATH = (Resolve-Path .deps).Path
python -u probe/deploy_theme.py upload      # 模板 + 主题文件（改了 templates/ 要重启）
python -u probe/serve_assets.py upload      # css/js/data 静态资源（不用重启）
python -u probe/activate_theme.py restart   # 仅改模板时执行，约 2.5–3 分钟
python -u probe/_wait_health.py             # 等健康 + 抽查五个路由
```

只改 `assets/` 下的文件时，跑第 2 条就行。
