## 二、上线链路（可重放）

1. **上传主题**：`python -u probe/deploy_theme.py upload` —— SFTP 把 `theme-doupi/` 推到 `data/themes/`。
2. **切主题**：`python -u probe/activate_theme.py patch` —— 改 MySQL 里 `/registry/configmaps/system` 的 `data.theme` 为 `{"active":"theme-doupi"}`，备份原行到 `notes/_backup-system-configmap.json`。
3. **建 Theme 资源行**：`python -u probe/register_theme.py apply` —— 见「三、坑 1」。
4. **建 /courses 页**：`python -u probe/clone_page.py` —— 克隆 `page-adg6crmr`（daily 那一页）成 `page-courses0001`（slug `courses`、title「课程」、permalink `/courses`）。
5. **重启 Halo**：`docker restart 1Panel-halo-UaWD`（约 2.5 分钟变 healthy）。改模板、改 DB 资源都必须重启才生效。
6. **静态资源交给 nginx**：`python -u probe/serve_assets.py all`（上传 assets + 往 vhost 插 alias + reload）。
7. **验收**：`python -u probe/deploy_theme.py status`，或直接 curl 六个路由。

回滚：把 `notes/_backup-system-configmap.json` 写回 `/registry/configmaps/system` → 重启 → 主题回到 `theme-Serenity`（Serenity 文件一直在 `data/themes/theme-Serenity/`，没动过）。

## 三、三个坑（都花了时间）

### 1. 自制主题的 `/themes/<name>/assets/*` 一律 404

DB 里切 `data.theme` 能让模板生效，但 Halo 不会为这个主题生成 `Theme` 资源行，资产 handler 于是不认它 —— 页面渲染出来了，却全裸无样式。
手工插 `/registry/theme.halo.run/themes/theme-doupi`（`status.phase: READY`）也没修好。

最终绕过：openresty 里加一段 alias，把静态文件从容器可见的目录直接发：

```nginx
location ^~ /themes/theme-doupi/assets/ {
    alias /www/sites/doupi123.top/theme/assets/;   # = 宿主机 /opt/1panel/www/sites/doupi123.top/theme/assets
    access_log off;
    expires -1;
    add_header Cache-Control "no-cache";           # 调试期不缓存，稳定后可改 7d
}
```

改完 `nginx -t && nginx -s reload`。**改主题 CSS/JS 之后要重新 `serve_assets.py upload`**，否则线上还是旧的。

### 2. Halo 不热加载模板，而且重启会回写内存态

`PUT`/DB 改 `spec.template` 后重启，改动会被内存里的旧状态覆盖回去。所以 `/daily`、`/courses` 没有走「按页配模板」，而是让 `templates/page.html` 自己按 `singlePage.spec.slug` 分派：

```
slug == 'daily'   → 时间轴
slug == 'courses' → 课程清单
其它              → singlePage.content.content
```

### 3. PAT 只有 post 作用域

Obsidian 插件里那个 `pat_...` 能发文章（`/apis/api.console.halo.run/v1alpha1/posts` 200），但 themes / singlepages / attachments / settings / configmaps 全 403。
所以主题、页面、插件开关都走的「MySQL `extensions` 表 + 重启」。读 JSON 必须 `mysql -r -N`，否则反斜杠被二次转义。

## 四、顺手关掉的三个插件

它们往页面注入飘落粒子、右侧悬浮球、全局美化脚本，和新主题打架：

```bash
python -u probe/disable_plugins.py floating-particles plugin-theme-roaming plugin-ui-beautify
docker restart 1Panel-halo-UaWD
```

要恢复的话把脚本里 `enabled` 改回 `True`（或后台插件页点启用）。

## 五、这次改到的模板/样式

- `templates/archives.html`：Halo 的 `archives` 是 `UrlContextListResult`，没有 `.pages`/`.months` 那种旧 API —— 用 `archives.total`、`hasPrevious`/`hasNext`，日期从标题 `#strings.substring(p.spec.title,5,10)` 取（`publishTime` 是 `Instant`，直接 format 会炸）。
- `assets/css/home.css`：`.ghost` 选择器改成 `span.ghost` —— 原来它同时命中了 `.btn.ghost`，把「读记录 / 资料柜」两个按钮放大成 320px 的巨字。
- `assets/css/home.css`（移动端 ≤620px）：导航不再 `display:none`，改成横向可滚动的一行，否则手机上完全进不去 `/daily`、`/courses`。
- `assets/js/courses.js`：`const DATA = window.COURSES || window.DAILY;` —— 数据文件导出的是 `window.COURSES`。
