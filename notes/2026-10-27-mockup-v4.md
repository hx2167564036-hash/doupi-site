# 2026-10-27 · 站点改版 mockup v4（苹果式开场 + 更炫的滚动）

## 为什么有 v4
用户看完 v3（中性的 Apple 式滚动）后说（m00660）：**「加入苹果式开场，现在的设计太素了，太单调了，虽然很简洁，但是不炫酷」**。
所以 v4 = v3 的动画骨架 + **电影感开场** + 一层「质感」（光晕、辉光、玻璃、巨号）。

## 开场（1.75 秒，可跳过）
| 时间 | 动作 |
|---|---|
| 0.10s | 中心柔光（冷蓝 + 暖橙两团）开始呼吸 |
| 0.15s | 数字 **0 → 490** 快速计数（900ms，`easeOutCubic`，配 `.18em` 字距） |
| 0.35s | 一道 1px 光带从顶部扫下（1.7s） |
| 0.78s | 「豆皮」浮现，字距从 `.72em` 收到 `.34em` |
| 1.05s | `DOUPI123.TOP · 个人档案` 淡入 |
| 1.75s | 幕布整体上移 `translateY(-100%)`（1.05s `cubic-bezier(.76,0,.24,1)`），内部同时 `scale(1.08)` 淡出 |
| — | 任意 `wheel/touchstart/keydown/click` 立刻跳过；`prefers-reduced-motion` 直接不显示；右下角常驻「点击 / 滚动 / 任意键 跳过」 |

幕布升起时给 `<html>` 加 `.revealed`，首屏 `.hero-inner` / `.hero-foot` 才播放
`heroIn`（`scale(1.035) → 1` + `translateY(20px) → 0`），形成「幕布拉开、内容落定」的接力。

## v4 相对 v3 新增
1. **开场幕**（上面那张表）
2. **极光背景**：三团 50vw 左右的柔光（冷蓝 / 暖橙 / 薄荷绿）`filter:blur(70px)`，20–32s 缓慢漂移；
   亮色用 `mix-blend-mode:multiply`，暗色自动切 `screen`
3. **鼠标光斑**：首屏内跟随光标的一团 720px 柔光（`pointer:fine` 才启用）
4. **记录区数字**改成金属渐变（`background-clip:text`）+ 背后一层辉光；滚动时 0→490、`scale(.92→1.04)`、`opacity(.35→1)`
5. **标题字距进场**：`.mask` 从 `letter-spacing:.06em` 收到正常（tracking-in）
6. **头像高光**：加载后一道 105° 白光扫过（`sheen` 2.6s，只播一次）
7. **能力区技术词跑马灯**（黑底，40s 循环，`nth-child(4n+1)` 高亮）
8. **玻璃卡片**：资料柜/视频卡 `backdrop-filter:saturate(140%) blur(14px)`，hover 时渐变描边（`mask-composite:exclude` 做 1px 边框）
9. **区块巨号**：每个 section 背后一个 `clamp(120px,21vw,320px)` 的描边数字（01/02/03/05），由 JS 从 `data-ghost` 生成
10. **首屏退场**：滚过首屏时 `scale(1→.95)` + 淡出

## 踩过的坑
- `shot.py` 之前把 `"path#intro-hold"` 当成文件路径 → `ERR_FILE_NOT_FOUND`。要先把 `#fragment` 拆出来，`as_uri()` 后再拼回。
- 文件 URL 不能带 `?query`（`file:///…?x=1` 会被当成文件名）⇒ 用 `#intro-hold` 哈希；JS 里 `/intro[-=]hold/` 同时兼容两种写法。
- hold 模式下 JS 提前 `return` 会让计数停在 0 ⇒ hold 时直接写死 490 再返回，截图才是「满编」状态。
- `.intro` 的 `overflow:hidden` 不影响 sticky；但 `html/body{overflow-x:hidden}` 会让记录区的 `position:sticky` 失效，必须用 `overflow-x:clip`（v3 已踩过）。
- PowerShell 不支持 heredoc，所有批量改动都写成 `probe/_build_v4.py`、`_patch_v4_*.py` 这类脚本再跑。
