# 2026-10-27 配色：从黑白到暖纸 + 赭红

## 起因

用户看完上线版（黑白 + 极简）说：「现在只有黑白有点太朴素了，虽然我要 simplicity，但是现在有点太 simple」。
前提没变：仍然要简洁、以内容为主，**只加一点颜色**，不做回原来那种炫光。

## 方案

一个强调色，不加第二个。

| 用途 | token | 值 |
| --- | --- | --- |
| 纸底 | `--bg` | `#FAF7F2` |
| 次级纸（引文段 / 卡内分栏） | `--bg-2` | `#F2EDE5` |
| 卡片 | `--surface` / `--card` | `#FFFDF9` |
| 墨 | `--ink` | `#1A1917` |
| 次级墨 | `--ink-2` | `#4A453E` |
| 灰字 | `--muted` | `#7E776C` |
| 细线 | `--line` / `--line-2` | `#E6DFD4` / `#EFE9DF` |
| **强调** | `--accent` | `#B4553B`（赭红） |
| 强调深 | `--accent-2` | `#8E3F2A` |
| 强调底 | `--accent-soft` | `#F7E9E3` |
| 强调线 | `--accent-line` | `rgba(180,85,59,.35)` |
| 深夜底 | `--dark` / `--dark-2` | `#141110` / `#1C1815` |

暗色模式同步换成暖黑（不是纯黑）：`--bg:#0B0A09`、`--accent:#E08A6E`。

## 强调色出现在哪儿（刻意克制）

- kicker 前一个 6px 赭色圆点
- 首屏事实条的数字、档案卡 `NO. 492`、`em b`
- 项目区编号与箭头只在 hover 时变赭
- 引文段的粗体、`记录` 固定区数字的渐变（墨 → 赭）
- 热力图：有字的格子用赭色深浅（42% / 80% / 78%）
- 选中文字 `::selection` 用 accent-soft
- 顶栏当前栏目 2px 赭色下划线
- 视频来源徽标（BILIBILI）从 B 站青改成赭色系
- 正文 `<b>` 的荧光条改成 16% 赭色薄条（原来是灰条）

首屏极光三团从冷色（蓝紫 / 桃 / 绿）改成暖色（`#f6d5c9` / `#ffe9cd` / `#dfe8d4`，留一团灰绿做对比）。

## 两个坑

1. **同选择器规则必须原地替换**：`home.css` 里早就有 `.vid .meta .src{color:#00AEEC; …}`，我追加一条同名规则想覆盖，结果我的守卫判断 `if ".meta .src{" not in s` 直接跳过，白白排版一轮。教训：改样式前先 `Select-String` 看这个选择器是不是已经存在。
2. **CSS-only 改动不用重启 Halo**：`serve_assets.py upload` 上传后浏览器刷新即生效；只有 `templates/*.html` 或 `theme.yaml` 变了才需要 `activate_theme.py restart`（约 2.5–3 分钟）。这一轮配色全靠上传，省下来的时间都花在截图核对了。
