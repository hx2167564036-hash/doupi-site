# /courses 课程详情页（mockup 版）

## 一、页面是什么

`mockups/v4/courses.html` —— 单文件、双击即看，和 v4 首页同一套配色与字体（`#FAFAFC` / `System` 栈 / `letter-spacing:-.011em`）。
首页第 03 区块「课程」底部的「按学期浏览全部 57 门课 ↗」链到这里。

结构：

- **顶部** sticky 导航（课程高亮）+ 大标题「课程」+ 一行统计：`5 个学期 · 57 门课 · 719 份课件 · 163 条章节在本地归档`。
- **左侧栏**：搜索框（课程名 / 课程号 / 章节点名都能搜）+ 学期切换（2026—2027 秋 11、2025—2026 春 9、2025—2026 秋 16、2024—2025 春 11、2024—2025 秋 10）。
- **右侧**：按学期列卡片。卡片标题行是课程名 + 课程号 chip（如 `B01118`）+ 右侧「16 份课件 / 无课件」状态点，下面一行 `学期 · N 讲 · 完整课程代码`。
- **点卡片展开**：上半「章节结构」（`01 第一章 … 08 文献综述`，来自教务的模块列表），下半「课件（本地归档 · 不下载）」按三列列文件名；超过 12 个文件时有「全部 N 份 ↗」。
- 没有任何下载链接 —— 文件只列名字。

## 二、数据从哪来（`probe/build_courses_page.py`）

只读「上下文中枢」的 sqlite（`D:\应用信息互联\data\context.db`）：

| 用途 | 表 / 字段 |
|---|---|
| 课程 | `tron_courses`：`id / name / code`（`(2026-2027-1)-B01118-C13001-1`）、`start_date` |
| 课件文件 | `tron_files`：`course_id → name`（719 条） |
| 章节模块 | `documents` 里 `kind='章节'` 的 `body`，形如「课程：X 第1讲 … 第8讲 …」 |

三个处理细节：

1. **只留真课程**：`code` 必须匹配 `^\(\d{4}-\d{4}-\d\)`，`晚自习` 这类 code 是 `_UUID_...` 的杂项丢掉。
2. **按「学年-学期」归并**：一开始按开课日期分组得到 6 个「学期」，其实同一学期有两个开课日，按 code 里的 `(2025-2026-2)` 归并后是 **5 个真实学期**；首页统计已同步改成 5。
3. **章节正则**要允许标题里再出现「第」字：`第\s*(\d+)\s*讲\s*([\s\S]*?)(?=\s*第\s*\d+\s*讲\s|\[来源\]|$)`。第一版用了 `[^第]*?`，碰见「第1讲 第一讲：」就断不住，57 门课只解析出 52 条章节；修好后是 **163 条**。

排序：学期倒序 → 有课件优先 → 有章节优先 → 课程名正序。第一版按名字倒序，结果「音乐鉴赏」排在第一位且展开是空的，观感很差。

## 三、刻意没放的东西

- **课件本体**：`.pdf / .pptx` 只在本地 `D:\应用信息互联\data\files\hzcu\<课程>\`，页面不提供任何下载或预览。
- **作业 212 份 / 考试 54 份 / 讨论 20 条 / 微信 74 条 / 手机通知 29 条**：完全不上站。
- **成绩、学分**：中枢里没有可信字段（`tron_courses` 无 credit/grade 列），不编。

## 四、怎么重新生成

```powershell
$env:PYTHONIOENCODING = 'utf-8'
python -u probe/build_courses_page.py        # → mockups/v4/courses.html
python -u probe/_hub_semesters2.py           # → notes/_hub_courses.json（首页区块用）
python -u probe/_patch_v4_courses.py         # 重建首页「课程」区块
```

截图（需要 `.deps` 里的 paramiko / websocket-client）：

```powershell
$env:PYTHONPATH = (Resolve-Path .deps).Path
python -u probe/shot.py mockups/v4/courses.html mockups/v4/shots/courses-page.png `
  --width 1440 --height 1020 --dsf 1 --viewport-only --settle 1.2 `
  --eval "document.querySelectorAll('.c-head')[0].click(); 'opened'"
```

`--eval` 是这次用到的技巧：截图前点开第一张卡片，否则整页都是收起的。

## 五、上线到 Halo 时怎么落

- 新主题 `theme-doupi` 里做一个 `templates/course.html`（或 `page_courses.html` 自定义模板），把这份数据接到主题的 `finder`：
  - 课程 = Halo 的「分类」或「标签」不现实（57 门），更适合做成**一个 JSON 附件** + 模板里 `fetch` 渲染，或者落成一张 Halo「单页」+ 自定义模板，数据用主题的 `settings.yaml` 里的多行 YAML 存。
  - 章节与文件清单属于本地知识库，不建议写进 Halo 数据库；生成静态 JSON 随主题一起发（`assets/data/courses.json`）即可。
- 上线前要定：课程页是否要搜索（前端 filter 足够）、是否需要「按学期锚点」直达。
