# 2026-10-27 · 站点改版 mockup v3（Apple 式滚动动效版）

## 为什么有 v3
用户看完 v2 后说（m00583）：**「现在是颜色的冲击，我不需要这个，我要的是动画，就像原来那样会变化，视觉上美观震撼。对于动画方面你可以参考 Apple 官网的设计」**。
结论：v2 的朱红 duotone、描边大字是「颜色冲击」，不是用户要的。v3 换成**中性色 + 克制动效**，
把「震撼」交给**运动本身**（滚动驱动、遮罩文字上浮、视差、逐列绘制、逐字点亮）。

## 动效编排（每一处为什么存在）
| 位置 | 触发 | 效果 | 参数 |
|---|---|---|---|
| 首屏标题「豆皮」 | 加载 | 遮罩上浮（`.mask > span` 从 `translateY(115%)` 到 0） | 1.15s `cubic-bezier(.16,1,.3,1)` |
| 首屏副文案 / 按钮 / 事实条 | 进入视口 | `opacity 0→1` + `translateY(20px)→0`，依次错峰 120/220/320/360ms | .95s |
| 头像卡 | 进入视口 | `scale(.965)→1` 轻微放大 | 1.2s |
| 头像卡 | 滚动 | 视差 `translate3d(0, -center*0.06, 0)` | rAF |
| 顶部进度条 | 滚动 | 宽度 0→100% | rAF |
| 导航 | 滚动 >40px | 加 `.solid`，底色变实 + 细分隔线 | .3s |
| 项目行 | 进入视口 | 依次 `zoom` 进场（0/90/180/270ms），hover 时整行软灰底 + 箭头右移 6px | .5s |
| 声明段 | 滚动 | **逐字点亮**（每个汉字 `opacity .16→1`，随滚动进度推进） | .35s linear |
| 记录区（`.pin`，280vh） | 滚动固定 | 数字 **0→490 随滚动递增**、`scale(.92→1.04)`、`opacity(.35→1)`；下方热力图**按列逐格点亮** | rAF |
| 能力区 | 进入视口 | 每行 fade 错峰 70ms（黑场） | .95s |
| 资料柜 | 进入视口 | 卡片 `zoom` 进场 + 数字 `0→N` 缓动计数 | 1.2s |
| 视频卡 | hover | 播放圆钮 `scale(1.08)` 且反色 | .5s |

全部动画都在 `prefers-reduced-motion: reduce` 时降级为静态（`.mask` 归位、`fade/zoom` 直接可见、
跑马灯停、数字直接置终值）。

## 与技术细节
- 统一的 `[data-in]` + IntersectionObserver（`rootMargin:0 0 -10% 0`）负责进场；`[data-par]` 负责视差。
- 滚动驱动统一走 **一个** `scroll` 监听 + rAF 节流（`ticking` 标记），只改 `transform/opacity/width`，不触发重排。
- 固定区进度 `p = (-rect.top) / (offsetHeight - innerHeight)`，数字 = `490 * min(1, p*1.12)`，
  热力图点亮列数 = `ceil(p * 总列数)`。
- 逐字点亮先把文本拆成 `<span>`（`Array.from(text)` 逐字，空白不参与），再按 `p` 点亮前 N 个字。
- 踩过的坑①：`html/body{overflow-x:hidden}` 会让 `position:sticky` 失效（记录区的固定滚动整块空白），
  改 `overflow-x:clip` 后正常。
- 踩过的坑②：第一次截图 `pin` 帧是纯白，因为 sticky 没生效（同上）。
- 踩过的坑③：移动端热力图 76 列会横向溢出，改成「≤620px 只画最近 28 周 + `--cell:10px`」。
- 截图命令：`python -u probe/shot.py mockups/v3/index.html out.png --width 1440 --height 900 --viewport-only --at "#journal@0.45"`。
