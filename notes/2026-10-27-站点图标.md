# 站点图标（2026-10-27）

标签页里原来是一个地球占位图（`<title>豆皮 · 项目、能力与 492 篇记录</title>` 左边那个）。现在换成自己的图标。

## 设计

一枚方形的「档案卡」印记，和整站的语言一致：

- 墨色底 `#16181C`（`--ink`），圆角半径 22%——像书脊上贴的标签
- 纸色 `#FAFAFC`（`--bg`）写一个「豆」字，微软雅黑 Bold，字号 0.52 × 边长
- 不加渐变、不加描边、不加阴影：缩到 16px 时，多一笔就糊

生成脚本 `probe/make_icon.py`（Pillow，无外部依赖）：

```powershell
$env:PYTHONPATH = (Resolve-Path '.deps').Path
python -u probe/make_icon.py
```

字号踩过一轮：0.62 在 312px 那一档笔画几乎贴边，缩到 0.52 才留出呼吸感。

| 文件 | 尺寸 | 用途 | 字节 |

| `icon-512.png` | 512 | manifest、结构化数据 | 13,479 |
| `favicon.ico` | 16 / 32 / 48 / 64 四档 | 老浏览器、Windows 快捷方式 | 5,441 |
| `favicon-32.png` | 32 | 现代浏览器标准图标 | 1,091 |
| `favicon-192.png` | 192 | Android / PWA | 5,811 |
| `apple-touch-icon.png` | 180 | iOS 添加到主屏 | 5,431 |

另有 `theme-doupi/assets/site.webmanifest`（672 B，192 + 512，512 标 `maskable`）。

## 挂到模板上

`probe/patch_favicon.py` 给 12 个模板的 `<head>` 统一插四条 link + `theme-color`：

```html
<link rel="icon" th:href="@{/assets/img/favicon.ico}" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" th:href="@{/assets/img/favicon-32.png}">
<link rel="apple-touch-icon" th:href="@{/assets/img/apple-touch-icon.png}">
<link rel="manifest" th:href="@{/assets/site.webmanifest}">
<meta name="theme-color" content="#FAFAFC">
```

## 两个踩过的坑

1. **必须写 `th:href="@{/assets/...}"`，不能写死 `href="/assets/..."`**。Halo 只会给 Thymeleaf 链接表达式补上 `/themes/theme-doupi/` 前缀和 `?v=1.0.0`；写死的 `/assets/...` 会 404（`{"detail":"No static resource..."}`）。这个坑和主题自身资源 404 是同一件事的两个面——主题用 nginx alias 供 `/themes/theme-doupi/assets/`，Halo 自己的 `/assets/` 路由对自制主题不生效。
2. **`probe/serve_assets.py` 的上传白名单要加 `.ico` 和 `.webmanifest`**，否则文件根本没传上去，服务器上只有 png。

## 顺带做的

`live.js` 的 `apply()` 末尾会把 `document.title` 与 `meta[name=description]` 里的「N 篇」同步成实时值——现在标签页标题会随文章数一起变（`492 篇` 是当下真值）。

## 还想要的

16px 那一档 CJK 单字本来就糊（笔画太多）。如果以后想要更锐的小图标，两条路：① 换成字母 `D` 或抽象印记；② 为 16px 单独画一版简化字形（只留横与框）。目前先保持「豆」——它在 32px 及以上很清楚，也和站名最直接。
