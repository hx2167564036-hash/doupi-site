## 截图工具
`probe/shot.py`（CDP，websocket-client 在 `.deps`）：
```
$env:PYTHONPATH = (Resolve-Path .deps).Path
python -u probe/shot.py mockups/v1/index.html mockups/v1/shots/desktop.png --width 1440 --dsf 1
python -u probe/shot.py mockups/v1/index.html mockups/v1/shots/mobile.png --width 390 --mobile --dsf 1 --height 844
```
坑：`--headless=new` 的 `--window-size` 在 Windows 上会被夹到最小 500px，`--headless=old` 又会让 innerWidth 变成 312，
所以必须走 CDP 的 `Emulation.setDeviceMetricsOverride` 才能拿到真 390 宽。截整页用 `Page.captureScreenshot` +
`clip` + `captureBeyondViewport`；截图前把 `.rv` 的 transition 关掉再 `add('in')`，否则会截到半透明。
